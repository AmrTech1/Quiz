# نظام الاختبارات الإلكترونية — Web + Telegram Sync

## البنية
```
project/
  web/            الموقع (Frontend) — افتح web/index.html أو استضفه على أي static hosting
    index.html
    css/style.css
    js/utils.js   دوال مساعدة (IDs, أكواد, CSV, toast)
    js/db.js      طبقة IndexedDB (الكاش المحلي)
    js/sync.js    SyncManager — يتصل بالـ Worker فقط (لا يعرف BOT_TOKEN أبدًا)
    js/app.js     كل منطق التطبيق (الطالب + لوحة المدير)
  worker/         الخادم الوسيط (Cloudflare Worker) — يحمي BOT_TOKEN
    worker.js
    wrangler.toml
```

## كيف تعمل المزامنة مع Telegram (بدون أي قاعدة بيانات خارجية)
- **الرفع (Push):** الـ Worker يرسل بيانات النظام كملف `data.json` إلى المحادثة عبر
  `sendDocument`، ثم يقوم بتثبيت هذه الرسالة (`pinChatMessage`).
- **الجلب (Pull):** الـ Worker يقرأ `getChat` ليحصل على `pinned_message` (وهو دائمًا
  آخر نسخة تم رفعها)، ثم يحمّل الملف المرفق بها.
- **ميزة إضافية:** كل نسخة سابقة تبقى في المحادثة كرسالة عادية → أرشيف/نسخ احتياطية
  تلقائية بدون أي عمل إضافي.
- **لماذا Worker وليس اتصال مباشر؟** لأن BOT_TOKEN لا يجب أن يظهر أبدًا في كود
  الموقع (يمكن لأي زائر رؤيته). الـ Worker هو الوحيد الذي يحمل التوكن (كـ Secret)
  وينفذ العمليات نيابة عن الموقع.

## خطوات التشغيل

### 1) إنشاء Telegram Bot ومحادثة التخزين
1. تحدث مع [@BotFather](https://t.me/BotFather) وأنشئ بوت جديد → احصل على `BOT_TOKEN`.
2. أنشئ **قناة خاصة** أو **مجموعة** ستكون مكان تخزين البيانات.
3. أضف البوت إليها كمشرف (Admin) مع صلاحية **تثبيت الرسائل (Pin Messages)**.
4. احصل على `CHAT_ID`:
   - أرسل أي رسالة في القناة/المجموعة.
   - افتح: `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`
   - ستجد `chat.id` في الرد (عادة رقم سالب للقنوات/المجموعات، مثل `-1001234567890`).

### 2) نشر الـ Worker (حماية التوكن)
يتطلب [Node.js](https://nodejs.org) و [wrangler](https://developers.cloudflare.com/workers/wrangler/):
```bash
cd worker
npm install -g wrangler   # إن لم يكن مثبتًا
wrangler login
wrangler secret put BOT_TOKEN     # الصق التوكن عند الطلب
wrangler secret put CHAT_ID       # الصق الـ chat id عند الطلب
wrangler deploy
```
بعد النشر ستحصل على رابط مثل: `https://quiz-sync-worker.<your-subdomain>.workers.dev`

> لا تضع `BOT_TOKEN` أو `CHAT_ID` داخل `worker.js` أو `wrangler.toml` مباشرة —
> استخدم `wrangler secret put` دائمًا حتى لا يظهرا في أي كود مرفوع.

### 3) تشغيل الموقع
- الأبسط: افتح `web/index.html` مباشرة في المتصفح، أو استضف مجلد `web/` على أي
  استضافة ثابتة (Cloudflare Pages, GitHub Pages, Netlify...).
- بعد فتح الموقع: **الإعدادات ← المزامنة ← الصق رابط الـ Worker ← احفظ ← مزامنة الآن**.

### 4) دخول لوحة المدير
- من الصفحة الرئيسية، أدخل في حقل "كود الاختبار": `@Amr0109`
- (كلمة المرور مضبوطة كثابت `ADMIN_PASSWORD` في `web/js/app.js` — يمكنك تغييرها من هناك)

> **ملاحظة أمان:** التحقق من كلمة مرور المدير يتم بالكامل في المتصفح (Frontend)،
> وهذا مناسب لاستخدام شخصي/محدود كما طلبت، لكنه ليس حماية قوية بمعنى تسجيل دخول
> حقيقي بخادم. أي شخص يقرأ كود الموقع سيجد الكلمة. إن احتجت حماية أقوى مستقبلًا،
> يمكن نقل التحقق إلى الـ Worker نفسه.

## العمل من أكثر من جهاز
1. من الجهاز الأول: أنشئ اختبارًا، أضف أسئلة، احفظ (يُرفع تلقائيًا لو كنت متصلًا
   بالإنترنت ورابط Worker مضبوط).
2. من الجهاز الثاني: افتح الموقع، اذهب للإعدادات، اضغط **مزامنة الآن** (أو ستتم
   المزامنة تلقائيًا عند فتح الصفحة الرئيسية إن كان لديك اتصال).
3. ستظهر نفس الاختبارات بنفس الأكواد والأسئلة، ويمكنك التعديل، والتعديل سينعكس
   على الجهاز الأول عند مزامنته.

## العمل بدون إنترنت
- تصفح الاختبارات الموجودة مسبقًا، وحل اختبار (يُحفظ تلقائيًا في IndexedDB) يعمل
  بدون إنترنت.
- عند فقد الاتصال أثناء العمل: التغييرات تُعلَّم كـ "غير مرفوعة" (`dirty`)، وعند
  عودة الإنترنت تُرفع تلقائيًا لـ Telegram.
- إنشاء/تعديل يتطلب رؤية أحدث نسخة من جهاز آخر يتطلب اتصالًا بالإنترنت لجلبها.

## النسخ الاحتياطي
- **تصدير Backup** (الإعدادات): يحفظ ملف JSON كامل مستقل عن Telegram تمامًا.
- **استيراد Backup**: يتحقق من صحة بنية الملف قبل الاستبدال، ويطلب تأكيدًا.

## ما الذي يمكن توسيعه لاحقًا
- سحب/إفلات لإعادة ترتيب الأسئلة (حاليًا أزرار ⬆️⬇️).
- تسجيل دخول حقيقي بالخادم للمدير بدل كلمة المرور الثابتة في الواجهة.
- حد أقصى فعلي لعدد المحاولات لكل طالب (حاليًا: منع الإعادة فقط إذا `allowRetake=false`
  بمطابقة الاسم).
